# Story B-5: Pink Tax check (parallel compare)
Status: Review (QA: see docs/qa/B-gate.md)

**Story:** As a shopper, I want my ticked items compared against alternatives, so that I can see where I paid extra.

## Acceptance Criteria
1. AC1 "Check for Pink Tax" button is enabled only when ??1 ticked, priced item exists.
2. AC2 Sends up to 5 ticked items to `POST /api/compare` in parallel with `Promise.allSettled`.
3. AC3 Each request body product: `{name, price_gbp: line_total/qty, source:"receipt", gender_target}`.
4. AC4 Progress rows per item: "Checking <name>?? ??"?? or "couldn't compare".
5. AC5 A failed/rejected item does not break the others or the totals.
6. AC6 No scoring on the client; all Comparison data comes from the API response.
7. AC7 Per-request timeout (e.g. 45 s) so the UI never hangs.
