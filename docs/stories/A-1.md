# Story A-1: lib/score.ts + tests
Status: Review

**Story:** As a shopper, I want correct, code-computed unit prices and scores, so that I can trust the Pink Tax number.

## Acceptance Criteria
- AC1: unit_price = price/quantity, null if either missing
- AC2: gap = (u_target-u_best)/u_best
- AC3: score = round(100*min(1,max(0,gap)/0.5)*equivalence)
- AC4: label: gap<0 Reverse gap; <20 No meaningful gap; <50 Moderate; else High
- AC5: savings_per_pack only when gap>0
- AC6: Units must match else Not enough data, score null
- AC7: Tests: clear gap, equal prices, reverse gap, missing data, unit mismatch
