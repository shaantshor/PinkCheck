# Story B-2: /api/receipt — read a receipt with Claude vision
Status: Review (QA: see docs/qa/B-gate.md)

**Story:** As a shopper, I want my receipt photo turned into structured line items, so that I don't have to type them.

## Acceptance Criteria
1. AC1 `POST /api/receipt` accepts `{image}` (base64 JPEG) and returns `{store, items, receipt_total}`.
2. AC2 Uses model `claude-sonnet-5-5` with vision and the prompt below.
3. AC3 Response validated by zod (`lib/receipt/schema.ts`); on invalid JSON retry once with "Return valid JSON only".
4. AC4 After the retry fails, or on any error: HTTP 422 with a friendly message ("Try a flatter, brighter photo").
5. AC5 `export const maxDuration = 60`.
6. AC6 Unreadable lines have `unreadable:true` and `line_total:null`; prices are never altered.

## Tasks
- [ ] T1 `lib/receipt/schema.ts`: zod schema `{store: string|null, items:[{raw_text,name,qty(default 1),line_total:number|null,gender_target:'female'|'male'|'neutral'|'unknown',unreadable:boolean}], receipt_total:number|null}` (AC3, AC6)
- [ ] T2 `lib/receipt/prompts.ts`: export `RECEIPT_SYSTEM_PROMPT` (AC2)
- [ ] T3 `app/api/receipt/route.ts`: call `anthropic` from `@/lib/claude`, parse with `extractJson`, validate, retry once, 422 on failure (AC1, AC3–5)
- [ ] T4 Manual curl with a sample image; `npm run build`

## Dev Notes
- Imports: `anthropic`, `extractJson` from `@/lib/claude`. Check how A wraps the client (key env var name).
- Prompt text (verbatim):
  > Read every purchased line item. Copy prices EXACTLY as printed in GBP. Keep raw_text. Expand abbreviations to a best-guess full product name (e.g. 'GIL VNS WMN RZR 3PK' → 'Gillette Venus women's razor 3 pack'). If a line is unreadable set unreadable:true and line_total null; NEVER guess. Classify gender_target from the product name (female/male/neutral/unknown). Ignore subtotals, VAT, payment and loyalty lines. Return JSON only: {store, items:[{raw_text,name,qty,line_total,gender_target,unreadable}], receipt_total}.
- Retry message appends: "Return valid JSON only".
- Never log the image or the receipt contents (privacy).

## Testing
`curl -X POST localhost:3000/api/receipt -d @body.json`; try a garbage image → 422; `npm run build`.
